# Sabor Já

Aplicativo de delivery feito em Flutter para o Projeto Final. Tem apenas a interface, sem backend, e os dados são fictícios.

## Telas

- **Login:** marca, campos de e-mail e senha com validação, "Esqueci minha senha", botão do Google e "Criar conta".
- **Início:** endereço, categorias e produtos em destaque.
- **Buscar:** carrossel de promoções, campo de pesquisa, filtros e lista de resultados.
- **Pedidos:** abas "Em andamento" e "Anteriores" com os cards dos pedidos, status, previsão de entrega e valor total.

## Como executar

```
flutter pub get
flutter run
```
